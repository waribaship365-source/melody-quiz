34路線モード（フラットUI版）

内容：
- index.html：クイズアプリ（6列・フラットUI）
- routes.csv：34路線の番号と路線名
- icons/001.png：京葉線の提供アイコン
- sw.js / manifest.webmanifest：オフライン利用・ホーム画面追加用

GitHub Pagesへの反映：
1. ZIPを展開します。
2. GitHubの solo-quiz リポジトリで index.html と sw.js を置き換えます。
3. icons フォルダをアップロードします（既存フォルダがあれば001.pngを追加）。
4. Commit changesします。
5. iPadのSafariで公開ページをオンラインで開き、再読み込みして新しい表示を確認します。

音源：
34路線モードでは001.mp3、002.mp3のように3桁番号のファイル名で音源を選択します。

アイコン：
icons/001.png ～ icons/105.png のように路線番号3桁.pngで配置します。現在は001.pngのみ実画像で、未提供分は仮の列車アイコンです。
